# Routing And Contamination Checklist

- [ ] Topic or keyword-only input starts at Plan.
- [ ] A supplied article starts at Audit.
- [ ] An Info-origin defect returns to Info and then Audit.
- [ ] A Plan-origin defect returns to Plan, then replays Info and Audit.
- [ ] Article-linked images consume only a Green audited article and visual brief.
- [ ] Standalone image work does not load article phases.
- [ ] No phase receives the full conversation transcript by default.
- [ ] Legacy snapshots are not auto-loaded.
- [ ] Public output contains no private evidence or legacy brand contamination.
- [ ] Final Output records truthful render/structural QA.
