## 写作风格指南

### 语气
- **同行对话**：以资深制造工程师给同事建议的语气写作，而非营销人员推销产品
- **证据优先**：每个论点必须引用 data 目录中的具体规格、认证或数据
- **零AI腔**：禁止 "delve", "embark", "unlock", "game-changer", "revolutionize", "cutting-edge", "in today's fast-paced world" 等 AI 常用词
- **去攻击性**：讨论竞品时用商业模式分析代替贬低性语言

### 禁止词汇表
| 类别 | 禁用词 |
|------|--------|
| AI动词 | delve, embark, craft, unlock, discover, utilize, dive deep, unveil, harness, elucidate, leverage |
| 营销夸张 | game-changer, skyrocket, revolutionize, disruptive, groundbreaking, cutting-edge, remarkable, world-class |
| 模糊比喻 | shed light, imagine, realm, tapestry, illuminate, navigating, landscape, ever-evolving |
| 陈词滥调 | you're not alone, in a world where, it remains to be seen, pivotal moment |
| 论文连接词 | hence, furthermore, however, moreover, in summary, in conclusion |
| 竞品攻击 | slow, cheap quality, untrustworthy, scam — 用商业模式分析替代 |
