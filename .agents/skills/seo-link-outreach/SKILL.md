# SEO Link Outreach

This Skill is installed but inactive. Read `extensions/link-building/extension.yaml` first.

Even after activation:

1. Accept only approved backlink-intelligence proposals.
2. Create draft materials and a human action checklist.
3. Exclude competitors, unsafe targets, unsupported claims, purchased-link schemes, PBNs, and manipulative anchors.
4. Stop at `WAITING_FOR_EXTERNAL_OUTREACH_APPROVAL`.
5. Never send email, submit a form, publish a guest post, upload a PR asset, or contact a third party without separate explicit approval.
