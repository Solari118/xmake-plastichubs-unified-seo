# SEO Checklist

Verify:

- Existing or suggested URL status is clear; canonical status is included for publishing packages.
- Meta Title is practical and not stuffed.
- Meta Description has clear buyer value.
- H1 focuses on the service or page topic.
- Primary topic is clear without an exact-match placement quota.
- Secondary keywords, query variants, and entities are used naturally without stuffing.
- Dominant intent and any meaningful secondary intent are stated.
- Headings support the reader's task rather than a keyword formula.
- FAQ is included only when real buyer questions justify it.
- Suggested internal links are relevant.
- A clear CTA is included.
- Author, reviewer, date, image, and schema fields are complete when the output is a publishing package.
- Plastichubs/xmake is absent from public copy and metadata.
