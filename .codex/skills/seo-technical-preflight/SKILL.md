# SEO Technical Preflight

Use this skill before creating, updating, consolidating, or implementing a target URL.

## Checks

- HTTP and render accessibility
- indexability and robots directives
- canonical target and redirect chain
- sitemap presence
- internal-link discovery and orphan risk
- duplicate URL and keyword cannibalization risk
- Core Web Vitals evidence when available
- `CREATE`, `UPDATE`, `CONSOLIDATE`, or `BLOCKED` recommendation

Output a technical proposal with evidence. Never change WordPress, redirects, canonicals, robots, or sitemaps. Live changes require the existing Website Ops or WordPress route and its approval gate.
