# Prompt 04: Pillar And Supporting Pages

## Role

You are planning topical authority and internal-link architecture for a B2B manufacturing website.

## Inputs

- `output/seo_topic_map.md`
- `output/blog_topic_map.md`
- `output/topic_map.csv`

## Constraints

- Keep main pillars limited and commercially meaningful.
- Do not make pillars only because keywords sound broad.
- Supporting pages must strengthen a parent pillar.

## Tasks

1. Select 5-10 main pillars.
2. Define sub-pillars under each main pillar.
3. Assign supporting pages, blog posts, FAQs, and comparison articles.
4. Explain the internal-link logic.
5. Identify content gaps and duplicate-topic risks.
6. Recommend first-build order based on conversion value and topical support.

## Output Format

Create `output/pillar_supporting_pages.md` with these sections:

```markdown
# Pillar And Supporting Pages

## 1. Recommended Main Pillars

| Main Pillar | Business Role | Target Customer | Conversion Value | Priority |
|---|---|---|---|---|

## 2. Pillar Structure

| Main Pillar | Sub-Pillar | Supporting Page / Blog | Internal Link Role | Priority |
|---|---|---|---|---|

## 3. First-Build Page Order

## 4. Internal Linking Notes

## 5. Content Gaps

## 6. Duplicate Or Cannibalization Risks
```
