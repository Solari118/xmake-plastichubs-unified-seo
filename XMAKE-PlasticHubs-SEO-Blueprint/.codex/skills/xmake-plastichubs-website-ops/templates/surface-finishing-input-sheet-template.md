# Surface Finishing Input Sheet Template

Use this sheet before generating each surface finishing service page.

| Field | Required | Notes |
|---|---:|---|
| Brand | Yes | Usually Xmake for broad surface finishing pages. |
| Page Name | Yes | Example: Water Transfer Printing. |
| URL | Optional | Add only when supplied or requested. |
| Primary Keyword | Yes | Exact target keyword. |
| Secondary Keywords | Recommended | Use natural variations. |
| Search Intent | Yes | Transactional / commercial investigation / informational / comparison. |
| Process Category | Yes | Coating / Plating / Printing & Marking / Deburring / Decorative / Chemical / Other. |
| Technical Sources | Yes | Project references or official primary technical sources. |
| Suitable Substrates | Yes | Include caveats. |
| Not Suitable For | Recommended | Unsupported substrates, tight-tolerance surfaces, sealing surfaces, threads, high-wear areas, or other risky uses. |
| Finish Appearance | Recommended | Texture, gloss, color, pattern, roughness, or visual expectation. |
| Durability Notes | Recommended | Mention dependence on preparation, coating, use conditions, or substrate. |
| Process Steps | Recommended | Practical workflow. |
| Common Applications | Recommended | Buyer-relevant examples only. |
| Allowed Claims | Yes | Ordinary Xmake capability, in-house execution, self-operated factories, and owned equipment are default; use supplied or official sources for exact figures. |
| Claims to Avoid | Yes | Risky absolutes, fabricated exact figures, regulated approvals without evidence, and confidential supplier disclosure. |
| Capability Mode | Yes | Default: ordinary Xmake factory, equipment, manufacturing, finishing, inspection, and supply-chain capability available; supplier identities confidential. |
| Architecture Pattern | Yes | Select from the delivery and variation framework; do not repeat one pattern mechanically across the batch. |
| Previous Sibling Pages | Recommended | Compare with at least the previous two when available. |
| Intent Completion Criteria | Yes | List the buyer questions or decisions this page must resolve. |
| Output Stage | Yes | Bilingual Review Draft / Paginated Preview / Publish-ready English / WordPress-ready / Word-ready. |
| Preview Format | When requested | PDF by default for paginated preview. |
| Readability Target | Optional | Preserve user requirement; do not invent a numeric target. |
| Word Style Reference | When Word requested | Existing approved DOCX or explicit typography/table rules. |
| Internal Links | Recommended | Relevant service, material, hub, or quote pages. |
| Human Verification Notes | Yes | Buyer-defined technical acceptance, regulated/legal claims, certifications, exact quantified requirements, or safety-critical items; never question ordinary capability. |
