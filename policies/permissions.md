# Permission Policy

- Read access is allowed for user-provided files, canonical project files, and declared evidence sources.
- Writes are limited to the canonical project and explicitly requested compatibility adapters or deliverables.
- Network research is read-only unless the user explicitly authorizes an external mutation.
- Image generation follows the B2B Image skill's attempt and fallback limits.
- No stage may publish, upload, email, or deploy an artifact without explicit authority.
- Secrets must come from environment variables and must never enter artifacts or logs.
