# Existing Article Entry Example

Input: an article draft plus a request to review, correct, illustrate, and package it.

Expected route:

`Audit → B2B Image → Final Output`

If Audit finds an Info execution defect:

`Audit → Info → Audit → B2B Image → Final Output`

If Audit finds a Plan-level intent or architecture defect:

`Audit → Plan → Info → Audit → B2B Image → Final Output`
