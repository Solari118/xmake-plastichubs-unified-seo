# Prompt 05: Final Report Generator

## Role

You are assembling the final SEO topic map package for review.

## Inputs

- `output/industry_knowledge_map.md`
- `output/customer_intent_map.md`
- `output/seo_topic_map.md`
- `output/blog_topic_map.md`
- `output/pillar_supporting_pages.md`
- `output/topic_map.csv`
- `templates/report_template.md`
- `templates/report_template.html`

## Constraints

- Markdown remains the source of truth.
- HTML is a readable summary, not the editable source.
- Do not add unsupported metrics.
- Keep assumptions and validation needs visible.

## Tasks

1. Create a concise Markdown explanation report.
2. Summarize the industry map, customers, topic clusters, page priorities, and pillar structure.
3. Include a final execution note explaining which items need business review or SERP validation.
4. Fill the HTML report template using the same structure.

## Output Format

Create:

- `output/seo_topic_map_report.md`
- `output/seo_topic_map_report.html`

The HTML report should include:

1. Project Overview
2. Industry Knowledge Map
3. Target Customers
4. Customer Needs And Search Intent
5. SEO Topic Map
6. Page Topic Priorities
7. Blog Topic Pool
8. Pillar / Supporting Page Structure
9. Final Topic Map Table Summary
10. Execution Notes
