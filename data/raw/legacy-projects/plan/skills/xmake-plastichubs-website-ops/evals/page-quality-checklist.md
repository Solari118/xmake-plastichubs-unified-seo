# Page Quality Checklist

Before final output, check:

- Page type is correctly identified.
- Template matches the page type.
- Brand is correct.
- Content is buyer-facing.
- Sections support decision-making, SEO, conversion, or technical clarity.
- Output is copy-ready.
- Headings are clear.
- Paragraphs are concise.
- Repetition is controlled.
- Each H2 has one distinct buyer job; overlapping selection or specification modules are merged.
- A private variation record explains how the page differs from the previous two sibling pages when available.
- Consecutive batch pages do not repeat the same architecture, hero angle, first decision aid, evidence form, CTA position, and closing pattern without an intent-based reason.
- Human verification notes are included when needed.
- Bilingual review drafts use readable stacked Markdown, Chinese first and English second.
- Raw HTML layout tags are absent from chat and Markdown review drafts.
- User-requested display or content corrections are persisted to the artifact.
- Output stage is explicit: Bilingual Review Draft, Paginated Preview, Publish-ready English, WordPress-ready, or Word-ready.
- Paginated preview and Word-ready claims include actual page-render inspection; unavailable rendering is reported as structural QA only.
- Fonts, bilingual punctuation, tables, headings, links, and page breaks are checked for Word-ready output.
