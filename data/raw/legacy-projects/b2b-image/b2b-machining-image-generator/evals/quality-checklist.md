# Image Output Quality Checklist

Before every image-tool call, verify:

- [ ] The content is suitable for AI and does not require tolerance, measurement, microscopy, or certification accuracy.
- [ ] One visual angle explains the main technical point; redundant illustration density was rejected.
- [ ] Reference research covered geometry, material, process/failure logic, and more than one source pattern when search was available.
- [ ] The prompt follows all six RD formula blocks in order.
- [ ] `#ea543f` is limited to annotations, guide lines, arrows, markers, and focal highlights.
- [ ] Background is white or very light neutral gray with flat studio lighting.
- [ ] Materials remain realistically colored; output is not pure monochrome.
- [ ] Labels are English, minimal, and limited to essential technical terms.
- [ ] Geometry is plausible and no unsupported dimensions or exact values are shown.
- [ ] The output is one coherent standalone image, not a collage, montage, contact sheet, or variant grid.
- [ ] Each requested asset uses a separate image-tool call.
- [ ] Negative constraints explicitly block anime, cartoon, cinematic styling, clutter, long text, and impossible geometry.

If any item fails, revise the prompt or reject AI generation before calling the image tool.
