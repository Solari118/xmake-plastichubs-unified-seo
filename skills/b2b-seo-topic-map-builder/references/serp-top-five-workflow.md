# Top-5 Organic SERP Benchmark Workflow — Legacy Compatibility Only

New runs must use `serp-top-ten-workflow.md`. Keep this file only to interpret older briefs; do not use it to plan new articles.

## Search Definition

Record before searching:

- exact `PRIMARY_KEYWORD` query
- target search engine
- country/locale
- language
- device assumption
- capture date
- target content type and intent

Default to Google organic desktop results for the brief's target market and language when the user supplies no alternative. Search results are a dated observation, not a universal view of the entire web.

## Result Selection

Capture the first five relevant non-sponsored organic editorial pages matching the intended intent.

- Exclude ads, shopping units, unrelated local packs, and duplicate URLs.
- Do not replace a result merely because it is inconvenient or weak.
- If a result is inaccessible, intent-mismatched, non-editorial, or duplicated, record the observed item and the reason for any substitute.
- Include the target brand's own page if it genuinely occupies an observed position; label it clearly.
- Use `Best-effort` when the tool cannot guarantee locale, device, personalization state, or exact organic position.

## Per-Page Analysis

For each result capture:

1. observed position, title, URL, domain, content type, author/date when visible
2. title, H1, and search-intent alignment
3. H2/H3 outline and information sequence
4. opening and answer strategy
5. reasoning flow and decision logic
6. technical depth, entities, questions, conditions, and limitations
7. evidence, citations, original data, examples, and expertise signals
8. tables, diagrams, tools, media, links, and usability
9. commercial integration and CTA
10. strongest elements, weak elements, and uncovered needs
11. plausible ranking contributors, explicitly labeled as hypotheses

Do not infer hidden backlink, engagement, authority, or ranking data unless a supplied tool measures it.

## Cross-SERP Synthesis

Produce:

- dominant intent and content-format consensus
- common coverage and entity set
- recurring strong structural or reasoning patterns
- evidence and media patterns
- commercial intensity pattern
- repeated weaknesses and unanswered questions
- content gaps and differentiation opportunities
- patterns worth adapting
- patterns to avoid
- minimum requirements for the new article to be more useful

## Originality Boundary

Borrow the function of a successful pattern, not its expression.

- Allowed: answer-first logic, decision tables, failure-mode coverage, source types, comparison dimensions, question categories, and useful content sequencing.
- Not allowed: copied sentences, lightly paraphrased passages, distinctive headings, proprietary examples, unique tables, or a near-duplicate outline from one page.
- Synthesize across all five sources and add target-brand expertise, evidence, or decision value that none provides alone.
